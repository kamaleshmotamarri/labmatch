# AEM Faculty data folder

Open **index.html** in a browser for a searchable directory with photos, summaries, and quizzes with revealable answers. No server or installation is needed.

- **people/**: one folder for each of the 35 people listed, containing photo.jpg, profile.md, and data.json.
- **faculty.json**: complete reusable dataset, including all 175 questions and answers, source URLs, and notes.
- **index.html**: offline browsing view.

Scope: all 21 Faculty, 10 Teaching & Research Faculty, and 4 Emeritus Faculty entries from https://cse.umn.edu/aem/aem-faculty, retrieved September 26, 2026. Names and roles follow that directory.
